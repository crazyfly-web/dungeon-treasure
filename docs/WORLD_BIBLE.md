# WORLD BIBLE v0.1

## 核心命題

**人類失去了一個世界。一群孩子，向地心尋找第二次機會。**

這不是教育遊戲。學生身分是世界的一部分；核心體驗是探索、求生、蒐集、改裝、風險判斷與逐步揭露未知世界。

## 世界

地表在數代以前的大崩壞後不再適合人類長期生活。倖存者遷入地下庇護所。現在的少年世代從未真正生活在天空之下。

庇護所資源逐漸衰退。少年操作員透過終端機遠端操控探索機器人，進入庇護所之外的廢棄設施尋找資源與技術。

最初的任務只是維持庇護所運作。隨探索深入，人們發現所有已知人類設施的下方仍存在巨大的未知空間。最終目標逐漸轉變為：尋找一個位於地心深處、能讓人類重新生活的完整生態環境。

## 核心遊戲循環

庇護所 → 組裝探索機 → 選擇裝備 → 回合制探索 → 戰鬥/搜刮 → 決定深入或撤退 → 帶回資源 → 修復庇護所/完成關鍵套件 → 解鎖更深區域。

探索機被摧毀時，操作員不會死亡。實體戰利品原則上留在失事地點；未來可設計殘骸回收機制。關鍵發現與已安全送回的永久進度保留。

## 區域骨架

1. **ZONE I — 廢棄地下鐵**：探索、戰鬥、能源、撤退。目標為工程探索套件。
2. **ZONE II — 沉沒都市**：水域、漏電、密封與水下移動。
3. **ZONE III — 工業深層**：高熱、重型機械、地熱能源。
4. **ZONE IV — 軍事禁區**：自動防禦、權限、電子戰。
5. **ZONE V — 地質深層**：離開人造空間，進入岩層與巨大洞穴。
6. **UNKNOWN — 地底生態圈**：首次發現自然繁衍的植物、水系與完整生態。
7. **終點 — 第二棲地**：確認適合人類長期生存的環境。

## 關鍵套件哲學

套件不是單純數值加成，而是「新的探索能力」。完成一套裝備，應該讓玩家能做以前做不到的事，並開啟新區域。

第一套：**工程探索套件**
- 液壓切割模組
- 高容量能源核心
- 工程識別晶片
- 重型機械臂

完成後可突破深層維修防爆門，進入下一區。

## 敘事原則

不以長篇說教解釋世界。故事主要存在於環境、遺物、舊資料、設備、殘骸與角色的短對話中。玩家先玩，再逐漸理解。

環境主題不直接說「要珍惜環境」。結局以人類面對第二次機會時的行動呈現：先理解新生態，再決定如何進入，而不是立刻征服與開發。

## 終局意象

探索機器人抵達地心深處，鏡頭第一次看見廣闊的水、植物與穩定生態。真正的 treasure 不是武器或黃金，而是人類再次擁有一個可以生活的世界。
