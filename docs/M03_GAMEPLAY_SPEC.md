# M0.3 — Mystery Dungeon Core：規則與實作進度

## 設計支柱

1. **回合就是成本**：移動、攻擊、待機、使用消耗品，都會讓敵人行動並消耗能源。
2. **強度不只靠等級**：升級主要提供少量耐久；戰術、消耗品、裝備和敵人特殊能力才是勝負關鍵。
3. **撤退也是勝利**：成功帶回 Scrap 和關鍵資料才會保存在庇護所；機器人毀損會失去當局戰利品。
4. **長期進度提供選擇**：基地升級優先改善整備資源，而不是無限制堆高攻擊。
5. **可預期的區域目標**：ZONE I 以工程套件 4/4 與 B10 防爆門為主要目標；ZONE II 尚未實作。

## 已落地（第一批 M0.3）

- 進遊戲先顯示庇護所整備資訊，Enter 出擊。
- 本機 localStorage 儲存庇護所 Scrap、工程資料進度及工坊等級（清除瀏覽器資料可能遺失）。
- 工坊使用 Scrap 升級，增加出擊維修包數量，最高 3 級。
- 每次出擊重置 LV、EXP、能源、消耗品與當局資源。
- 每回合能源 -1，能源耗盡開始損傷；長時間停留亦會造成壓力。
- H 使用維修包、Q 施放 EMP、句點或空白鍵待機修復、E 啟動四回合撤離。
- 經驗升級只提供小幅耐久，不再每級提高攻擊。
- 地下鐵區域延長至 B10；工程套件 4/4 是防爆門目標。

## 目前測試方式

```bash
git pull
npm install
npm run build
npm run dev
```

進遊戲按 Enter 出擊。移動用方向鍵或 WASD，H 維修、Q EMP、. 待機、E 撤離；返回庇護所按 R。庇護所按 1 升級工坊。

**注意**：目前第一批改動尚未在本機執行 TypeScript 編譯或實際瀏覽器驗證，若 build 出現錯誤，請保留完整輸出以便修正。
